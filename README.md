# sushi-landing-page

## О проекте
Это один из первых учебных проектов, выполненных в рамках курса по веб-разработке. Проект представляет собой одностраничный лендинг, посвящённый суши. В проекте использованы базовые технологии: HTML и CSS.

## Особенности
- Статическая верстка без адаптивности (только для десктопной версии)
- Использование семантических тегов HTML5
- Стилизация с помощью CSS (Пока без Flexbox и Grid)
- Простая структура и понятный код, что облегчает изучение основ веб-разработки

## Технологии
- HTML5
- CSS3

## Как запустить проект
1. Склонируйте репозиторий или скачайте архив с проектом.
2. Откройте файл `index.html` в любом современном браузере.
